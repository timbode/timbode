I lead [Quicopt](https://quicopt.com) — a quantum-inspired optimization spin-off out of the [Institute for Quantum Computing Analytics](https://www.fz-juelich.de/en/pgi/pgi-12) (PGI-12) at [Forschungszentrum Jülich](https://www.fz-juelich.de/en).

### Software Packages:
  - Creator of [MFAOA.jl](https://github.com/Quicopt/MFAOA.jl), a `Julia` package that implements the [Mean-Field Approximate Optimization Algorithm](https://doi.org/10.1103/PRXQuantum.4.030335).
  - Co-author of [KadanoffBaym.jl](https://github.com/NonequilibriumDynamics/KadanoffBaym.jl), a state-of-the-art `Julia` package for solving Kadanoff-Baym equations.
